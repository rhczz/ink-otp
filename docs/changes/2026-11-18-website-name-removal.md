# 官网隐私页移除个人姓名

## 范围与验收

用户要求官网页面不显示个人姓名。隐私页改用独立开发者表述，保留隐私联系邮箱。检查官网发布目录无该姓名，隐私页标题、地址和邮件链接有效。已发布的安装包和审核资料不在本次修改范围内。

## 实际结果

- 已检查官网文件树，页面没有显示该姓名。两页的本地链接、锚点、正式地址及联系邮箱均已核对。
- 已发布的 0.5.1 APK 内置较早的声明，仍含姓名。部署新版页面后两份声明有差异。华为审核会核对开发者名称及应用内外声明内容，本次新版网页不能视为与现有 APK 配套的提审材料。 [华为隐私政策审核说明](https://developer.huawei.com/consumer/cn/doc/app/faq-01/)
