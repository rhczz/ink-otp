# Mac 切换应用、解锁与添加账号

## 为什么做

[桌面 Beta 1](2026-11-18-macos-native-parity.md) 在返回验证码库、隐藏窗口内容和手动输入设置链接时，与 Android 0.5.3 存在可见差异。本次以 [Android 交互规则](../../spec/android-interaction.md) 为基准修正桌面行为。

## 原来怎样

未开启每次进入验证时，后台超时后回到桌面窗口需要再点一次解锁。失焦到锁定之间仍可看见账号名称与已打开的弹层。手动添加支持 Base32，完整设置链接需要从另一个菜单进入。

## 范围与验收

在 GitHub Actions 验证普通自动锁定后返回、手动锁定后的保持锁定、隐藏账号和弹层、完整设置链接的字段解析。使用相同的设备钥匙串授权规则，恢复路径继续遵守既有系统身份验证策略。发布后检查通用 DMG 与校验文件。真实设备的 Touch ID、相机权限和辅助功能体验分别记录。

覆盖升级还需验证临时签名变化后，原恢复口令能重新绑定普通设备钥匙串。自动解锁不应卡在后台的钥匙串授权框。主动点击解锁时保留系统钥匙串授权入口，供没有设置恢复口令的旧用户尝试打开其已有设备绑定。错误口令、绑定失败或退出时应保留原库及恢复能力。

另以 Android 发布标签中的 `VaultActions`、`ItemDetailScreen`、`VaultViewModel` 核对三条行为。启用隐藏时只能通过设置恢复显示。HOTP 迁移后保留参数和计数器，不能在界面生成、复制或推进。授权窗口导致的后台宽限最长两分钟。用同一组公开的 HOTP 备份验证数据保真，在界面检查不可用操作。

诊断页的刷新按钮原来仅更新时间标签。本次纳入实际 TOTP 重算、与资源采样分离，以及关于页和相机权限说明中的离线隐私入口。检查阅读后返回不会触发相机授权。

## 实际结果

[正式候选的 macOS 15 桌面测试](https://github.com/rhczz/ink-otp/actions/runs/44465149032/job/135368400341)全部通过。GitHub 运行器先从公开 DMG 启动 Beta 1，创建加密库和测试账号，再把候选应用替换到同一位置。原恢复口令可打开旧账号，冷启动和后续设备解锁也能使用这份库。

- 手动输入完整设置链接，预览显示服务名、账号、SHA256、8 位和 60 秒。保存后可在库中找到该账号。
- 切到 Finder 后，辅助功能读不到保存的账号和在编辑的输入框。超时前返回可继续未保存的草稿。立即锁定模式下的自动锁定会清除草稿，返回应用后能自动打开库。主动锁定后仍需点击解锁。
- 隐藏状态下复制 TOTP，剪贴板收到 8 位数字，界面和辅助功能继续隐藏验证码。从系统文件选择器导入 HOTP 后，详情保留计数器 10300，界面不提供生成和复制操作。
- 诊断页重算两个 TOTP，资源采样值保持原样。关于页和相机说明页均能显示随包隐私正文并返回原页。阅读操作保留了原有的相机授权状态。

[早期升级测试](https://github.com/rhczz/ink-otp/actions/runs/44458961485)发现窗口已遮住时，原生输入框仍可从辅助功能树读取。修复将敏感控件从失焦窗口移除，并将草稿状态保留在编辑器里。最终回归同时验证了隐藏和恢复。

同一份应用源码还在 [macOS 26 补充验收](https://github.com/rhczz/ink-otp/actions/runs/44467199287)通过全部六项桌面测试。Apple Silicon 运行器为 macOS 26.7.2、Xcode 26.6，Intel 构建继续使用 macOS 15。运行器也完成了真实备份互读、通用 DMG 打包和挂载验证。

[Beta 2 标签发布流程](https://github.com/rhczz/ink-otp/actions/runs/44468564960)会对合入 master 的版本重新执行双架构构建、备份互读与桌面升级。安装包和对应 SHA-256 文件使用同一个[公开 Release](https://github.com/rhczz/ink-otp/releases/tag/macos-v0.1.0-beta.2)。

两种架构的内核覆盖率见[跨端记录](2026-11-19-macos-cross-platform.md)。已打包应用的桌面测试没有插桩，未测其源码行及分支覆盖率。真实 Mac 的 Touch ID、登录密码授权与取消、相机扫码、VoiceOver 听感和 Gatekeeper 首次打开均未验证。临时签名公测版的每次进入身份验证限制见 [EX-008](../exceptions.md)。
