# InkOTP 0.5 Android 公测

## 为什么做

0.4.3 已提供签名 APK 和日常出码功能。用户决定推进 0.5 公测，补齐首启与锁定时的备份恢复、升级和真机验收流程、对外指南与反馈入口，并为 InkOTP 设计可长期使用的原创应用标志。

## 范围和验收方式

- 首启可直接恢复。已有库打不开时可主动从独立备份救援，预览和明确确认后才替换，原库密文保留在应用私有目录。每次进入时验证开启的设备，恢复须经 Android 系统授权并继续执行原策略。备份口令和新本机恢复口令分别输入。现有已解锁导入保留本机口令。
- 解密阶段提供取消，取消后不采用旧结果或提交数据。测试正确与错误口令、文件损坏、认证取消、后台和重复操作，以及本地写入失败。
- 验证 0.4.x 保存的库、密钥包装、账号顺序、验证码参数和设置。复用现有备份夹具和格式对拍，增加有针对性的宿主迁移用例。发布说明保留真机升级、重装与跨设备恢复、真实 Aegis/2FAS、系统认证、相机与隐私的待测结果。只在具有测试数据的设备上运行清除数据和重装用例。
- 诊断区分系统时间设置状态与手工自查，支持打开日期与时间设置。添加菜单在大字号下可滚动显示辅助文字。保持 Quiet Ink 交互与配色，原创图标支持 Android 启动器遮罩和主题单色图标。
- 应用版本为 `0.5.0-beta.1`（versionCode 7），关于页标明公测版。保留包名、发布证书与备份格式。对外说明安装、权限、数据处理、兼容范围及普通和安全反馈。运行 Makefile 验证和 CI 门禁，从远端主分支签名发布，重新下载后核对签名、哈希和来源。

## 实际结果

0.4.3 的备份导入在解锁后的设置页。0.5 新增首启和锁定页「从备份恢复」。例如旧库头部损坏时，可选择事先导出的加密备份，预览数量与兼容提醒，再设置本机新口令。已有库替换前原子写入一份原始密文副本，无法保全原文件即终止。原来开启系统认证的库仍需系统授权，恢复后继续保留该策略。旧库无法解锁时，重建的库采用普通本机设置默认值。正常覆盖更新保留现有设置。

解密时可点取消或返回，结果作废。已有库替换前仍可退出确认；原子提交开始后以磁盘提交结果为准。选择备份、错误口令或失败的原库保全均有回归检查。格式与密钥包装沿用现有契约。参见 [交互规格](../../spec/android-interaction.md)与[本机库规格](../../spec/vault-format.md)。

诊断页分别显示系统自动设置时间与手工核对清单，提供 Android 日期与时间设置入口，时钟变更提示来自检测到的跳变。添加菜单保留同一个弹层，长文案可换行，空间不足时可滚动。新版应用图标采用六片斜切几何形，以 3+3 表达验证码，中央负形形成笔迹，钴蓝点色与 Quiet Ink 一致。启动器的普通、圆形和单色主题图标复用同一矢量路径，「关于」页显示同一标志和公测版身份。

安装、备份、数据说明与真机用例集中在 [0.5 公测指南](../testing/0.5-public-beta.md)。普通问题用 GitHub Issues，安全报告使用 GitHub 的 [私下报告表单](https://github.com/rhczz/ink-otp/security/advisories/new)。本次已启用并复核私下报告开关。

### 真机待验证

ADB 检查无已授权设备。覆盖安装和安装取消、系统生物识别、相机与文件提供方、重装与跨设备恢复、Aegis 和 2FAS 实际 App 操作、最近任务、跨应用剪贴板、TalkBack、启动器与手机性能均待验证。公测使用同签名 APK，真机结果按 [公测指南](../testing/0.5-public-beta.md)逐项补记。为待测机型保留旧验证器与已验证的备份。
