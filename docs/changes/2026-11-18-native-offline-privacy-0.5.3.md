# InkOTP 0.5.3 原生离线隐私声明

## 为什么做

用户在真机安装 0.5.2 后，从「查看完整隐私声明」进入页面时，WebView 报告本地 data URL 加载失败。旧拦截器给包括本地文档在内的请求统一返回 403。Android 文档确认拦截回调会处理 data URL。这次修复 App 内的离线阅读。 [Android WebViewClient](https://developer.android.com/reference/android/webkit/WebViewClient)上一版随包内容见 [0.5.2 同步记录](2026-11-18-privacy-sync-0.5.2.md)。

## 范围与验收

- 从同一份随包的官网正文提取标题、段落、列表、日期和链接，用 Quiet Ink 的原生 Compose 组件显示。去除 WebView 和页面样式资源。
- 正文未改时保留原同意修订值。用户在首次确认之前也能查看全文并返回，阅读时不会打开账号库。其他查看入口共用同一阅读页，外部链接由用户点击后交给系统。
- 核对官网与内置文本完整性、原生界面首尾内容、失败/取消与声明同意状态。使用原证书交付 0.5.3（版本代码 10）本机签名包，真机复测单独记录。

## 实际结果

- 通过本机 `make ci`。核心 105 项，行覆盖 94.50%，分支 70.59%。App 183 项，行覆盖 84.17%，分支 60.95%。Python 42 项，Lint、备份互通、权限和 APK 对齐门禁均通过。
- 回归测试覆盖同意前查看正文、滚动到末节、返回与拒绝、同意记录写入失败，以及再次进入后的确认保留。逐段核对官网正文及链接，另测试中文与表情符号的链接位置。
- 从 0.5.2 签名 APK 抽出的政策文件与 0.5.3 构建逐字节一致。新 APK 的隐私资源只有源码文件，阅读时由原生界面展示。维护官网正文时保留可解析的配对标签，CI 会核对所有段落和链接。
- 本机签名、权限及哈希见交付目录的 `build-info.json` 和 `SHA256SUMS`。没有可用真机或模拟器。原报错设备的断网阅读、大字号与读屏、外部链接和覆盖安装仍待复测。
