# InkOTP 0.5.2 同步内置隐私声明

## 为什么做

官网已改用独立开发者表述，公开的 0.5.1 仍携带旧声明。用户确认按新版本发布，以便原下载及校验信息可以持续追溯。

## 范围与验收

- Android 版本升至 0.5.2，版本代码升至 9。继续从官网同一源文件打包离线声明。
- 核对官网部署文件、生成资源和公开 APK 内隐私声明一致。使用既有证书走 GitHub 发布，复核签名、权限和校验文件。

## 实际结果

- 本机通过离线声明及关于页回归。打包资源与官网部署文件逐字节一致。仓库文件门禁和补丁空白检查通过。
- 公开发布对应 GitHub Release 的签名验证任务及随包公布的构建来源和校验文件。真机覆盖升级、离线阅读、相机和系统认证未验证。
