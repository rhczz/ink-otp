# 整理仓库文档与 TOTP 原理说明

## 为什么改

README 混排了安装说明、早期里程碑、历史测试数据和构建命令。新读者难以先找到下载入口，也看不到 InkOTP 与登录网站如何共同完成 TOTP 验证。部分平台、构建与验证文档还在引用旧版功能或验收方式。

## 范围和验收

README 保留产品介绍、下载、基本用法和带图的 TOTP 说明。将工具链、日常开发和发布入口放到文档索引下，整理现行平台、互通、安全和验证说明。核对链接、当前实现与发布限制，并用独立参考实现复算公开的 TOTP 示例。历史交付记录继续作为历史证据使用。

- README 从 89 行收至 49 行，先介绍安装和迁移，再用时序图说明网站和验证器如何绑定、出码和验码。进度和验收记录统一从文档索引进入。
