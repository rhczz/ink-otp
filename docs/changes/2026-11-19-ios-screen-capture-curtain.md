# iOS 录屏与后台遮挡

iOS 首次预览版的场景遮挡层会让触摸穿过。录屏提示位于被覆盖的 SwiftUI 根视图中，应用弹层也没有统一的无障碍保护。此次修正场景中的遮挡、焦点及前后台恢复，并沿用 [iOS 真机交付验证](2026-11-19-ios-device-verification.md) 的发布流程。

前台检测到录屏或镜像时，独立窗口显示本地化提示。原窗口暂停交互，VoiceOver 只能读取遮挡提示。应用未激活时只显示空白幕布，系统身份验证和文件选择仍按原生流程运行。恢复前台且停止捕获后，幕布撤下，原窗口恢复交互与无障碍。

验收覆盖捕获状态开始与停止、切后台与回前台，以及捕获提示的 VoiceOver 可达性配置。模拟器测试不触发真实录屏或镜像。Face ID、系统 Files 面板与 VoiceOver 的真机组合验证未验证。

## 实际结果

GitHub Actions 在 iOS 26.2 的 iPhone 17 Pro 模拟器上通过 3 项幕布测试，覆盖前台捕获状态切换、后台空白遮挡，以及只有本地化提示对无障碍可见的配置。包含这三项在内的 iPhone XCTest 共 19 项通过。物理录屏、镜像、VoiceOver 手势及系统认证组合仍待真机核对。[测试日志](https://github.com/rhczz/ink-otp/actions/runs/44464194447/job/135357893937)
