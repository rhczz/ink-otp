# Mac 从图片添加二维码账号

## 为什么做

[Beta 2 的桌面验收](2026-11-19-macos-desktop-lifecycle.md)已覆盖设置链接、相机用途说明和备份文件选择。用户也能在不授予相机权限的情况下，从现有图片添加账号。这条路径还需验证系统文件面板交给 Vision 的图像能否正确进入预览并保存。

## 范围与验收

GitHub 托管 Mac 从已有公共 `otpauth` 用例生成测试图片。桌面 XCTest 从添加菜单进入系统图片选择器，核对单个二维码的账号参数，检查取消文件选择、取消预览、无二维码和多个账号二维码时原库不变，再保存有效账号并重新打开确认。对已发布 Beta 2 的 DMG 复验相同路径。图库图片和实体摄像头分别验收。
