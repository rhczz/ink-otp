## 如何新增记录

文件名使用 `YYYY-MM-DD-主题.md`。先描述用户遇到的问题或希望得到的能力，再说明改动、验证结果和剩余事项。小改动可以简短，复杂改动按用户流程展开；不要求每篇套用相同数量的标题。

涉及故障时，说明现象、复现条件、原因、修复和回归验证。仅做调查时，记录证据、结论及没有确认的部分。不要在文档里放真实密钥、验证码、口令或个人备份。
