# Android 公测准备度评估

## 为什么做

用户希望判断当前 Android 版距离公测还差什么。项目已有自用内测与 GitHub 预发布流程。本次评估以面向外部用户招募试用为公测场景，参考正式版验收清单判定风险。公测门槛是本次建议，项目尚无单独批准的公测规格。

## 范围与验收方式

- 核对最新远端 master、版本标签、预发布资产与 CI 报告，确认评估对应的源码和安装包。
- 核对应用恢复、认证、升级、隐私和备份互通的实际入口、自动测试和真机记录。
- 写明建议在扩大发放前补齐的事项、可延后到 1.0 的事项和仍未验证的用例。

## 公开招募前建议补齐

| 优先事项 | 当前差距和建议验收 |
|---|---|
| **备份救援能走完** | 正常解锁后可以导入。遇到损坏库，App 会保留原文件并提示使用备份，但锁定页没有恢复入口，首启也需要先建库再到设置里导入。补上首启引导和损坏库恢复流程，验证正确备份可恢复、错误口令或截断文件不会改写原库、取消或旧任务完成不会提交半成品。现有预览可取消，解密处理中暂时不能主动取消。 |
| **覆盖升级后账号能继续出码** | 0.4.3 增加本机包装，旧的设备绑定、口令、旧生物识别或每次进入验证配置都应验证。用签名 APK 覆盖安装后核对账号数量、排序、当前码、恢复口令和设置。取消 Android 安装后旧版仍可用，取消初次迁移认证后可重试。分别测试认证成功、失败、取消、切后台及指纹变化后重新绑定。 |
| **真机恢复、互通和隐私验证** | 用公开测试账号先导出，再重装恢复并换第二台设备导入，覆盖旧 `.2fab` 与 Aegis、2FAS 真 App 双向交换。至少分别覆盖 Android 8–10 和 11+ 两条系统验证路径，记录机型和系统版本。验证相机拒权、图片和文件选择取消、锁定后屏幕、最近任务、隐藏码读屏与跨应用剪贴板。真机冷启动、解锁、长列表和导入的耗时与内存仍待测，先记基线再定是否优化。 |
| **对外安装和反馈说明** | 统一 0.4.3 之后的下载、校验、覆盖更新与备份恢复指引。旧的统一手机指南还指向 0.4.2。列出已测设备和已知限制，明确相机权限、离线行为、错误反馈与私下报告漏洞的入口。现有安全政策只列 v1.0.x 为受支持版本，公测前需明确 beta 支持范围。 |

恢复与取消的依据见 [ViewModel 的备份流程](../../android/app/src/main/kotlin/io/github/rhczz/inkotp/app/VaultViewModel.kt#L400)、[应用导航](../../android/app/src/main/kotlin/io/github/rhczz/inkotp/ui/navigation/InkApp.kt#L225)和[设备包装规格](../../spec/vault-format.md#7-设备包装不在本文件中)。真机复测参考 [0.4.3 待测项](2026-11-18-android-entry-privacy-and-settings.md#真机待复测)、[M4 手机指南](../testing/m4-phone-test.md)和[格式矩阵](../../spec/interoperability.md)。

## 其余已知缺口

- 诊断页已经拆开验证码重算和资源刷新，但仍把选对账号、备用码和密钥输入显示成通过，自动时间开关也不能证明时钟准确。修正这些状态和系统时间设置入口。0.4.3 已记录添加弹层在 200% 字号下裁切，关键流程建议在公开招募前复核。见 [诊断源码](../../android/app/src/main/kotlin/io/github/rhczz/inkotp/ui/screens/DiagnosticsScreen.kt#L91)和 [0.4.3 开发记录](2026-11-18-android-entry-privacy-and-settings.md)。
- 拖拽排序、完整中英双语、图标编辑、完整无障碍与性能矩阵可以随 1.0 收尾。正式版还要核对完整第三方 notices、Gradle 依赖校验元数据和解析器十万输入 fuzz 的可复现实验。仓库未找到后两项的配置或结果。见[例外登记](../exceptions.md)和[发布清单](../release-checklist.md)。
- 现有发布链路面向 GitHub APK 直装。若公测指应用商店测试，还需按选定渠道核对其测试轨道、上架材料和签名升级方案。渠道与具体规则本次未评估。

## 判断与限制

0.4.3 可以继续小范围试用。扩大招募前，建议先补应用内恢复和长导入退出路径，交付一个保持签名的候选 APK，用测试账号完成一次覆盖升级、一次重装和跨设备恢复，再把复测结果和已知限制放进对应版本说明。真实硬件、跨应用互通、手机性能及 M3 真机验收均未验证。本次是准备度评估，仅新增本记录与索引。
