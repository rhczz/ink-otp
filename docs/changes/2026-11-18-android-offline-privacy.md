# InkOTP 隐私声明核查与 Android 离线阅读

## 为什么做

准备向华为应用市场提交 Android 安装包。官网已提供隐私声明，旧 APK 的关于页仅有简短说明。需要核准 App、官网和开发者邮箱各自如何处理信息，并让用户在断网时也能查阅与官网一致的全文。

## 范围与验收

- 以中国大陆法规及华为官方审核要求为本次分发基准，同时核查欧盟、英国、美国及其他代表性市场的适用条件。对照实际权限、数据流、备份、剪贴板及第三方依赖。官网和邮件仅披露实际用途、信息类型和保留依据。
- 以官网静态 HTML 为政策文本来源。声明全文随 APK 离线分发，在首次使用、设置、关于和扫码授权流程可查看。首启与旧版本升级可在知情后选择是否开始使用，本机记录声明修订。
- 在申请相机权限前解释用途和可选替代方式。验证同意、拒绝、返回、撤回、并发与应用升级，并保留厂商设备待测情况。
- 交付使用现有发布证书签名的 0.5.1，versionCode 8，验证权限、证书、资源和 APK 哈希。用户自行在官网和华为平台部署及提交。

## 审查与处理

- 将应用在设备上处理账号标识、密钥、图片和备份的事实写清楚。开发者无法通过应用取得这些数据。官网请求和主动来信另有处理目的、接收方和权利渠道，不能用应用的离线属性概括。处理或启用相机前先展示必要信息，应用内可拒绝或撤回。相机独立授权，拒绝后仍可使用替代方式。 [《个人信息保护法》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_f374e8245320413181742e6d1baf4366.html) · [华为审核指南第 7 节](https://developer.huawei.com/consumer/cn/doc/doccenter-submission/50104/)
- 对照代码列出扫码帧、选定文件、系统认证、界面保护、剪贴板、诊断和开源组件。说明救援副本、系统备份排除配置、明文导出含密钥、卸载后自行导出的文件仍由用户管理。去除全设备适用的绝对承诺，保留法定权利。
- 官网首页和正文使用平台中立的措辞。声明说明网站交付、防滥用和处理邮件等目的、保留依据及联系渠道。按用户要求，正文不列具体托管、邮箱转发去向或统一的留存天数。运维配置变动如果引入面向用户的追踪、额外处理或跨境传输，需要依实际操作重新判断义务。 [中国数据跨境流动规定](https://www.cac.gov.cn/2024-03/22/c_1712776611775634.htm)
- 免费或开源分发也要核实目标地区的适用条件。欧盟和英国的适用范围受面向当地用户提供服务、监测等事实影响。美国需避免作出与实际行为不符的隐私承诺，州法适用门槛和儿童保护要求分开判断。巴西、加拿大和日本同样以适用范围、实际数据流及分发方式为基础。此次是针对当前版本的风险核查。具体目标市场、商业化、加密进出口、备案或安全义务需要依实际发布计划核定。 [欧盟 GDPR](https://eur-lex.europa.eu/eli/reg/2016/679/oj/eng) · [英国 ICO 适用范围](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/personal-information-what-is-it/who-does-the-uk-gdpr-apply-to/) · [FTC 隐私执法](https://www.ftc.gov/news-events/topics/protecting-consumer-privacy-security/privacy-security-enforcement) · [加州 CCPA](https://oag.ca.gov/privacy/ccpa) · [巴西 LGPD](https://www.gov.br/anpd/pt-br/centrais-de-conteudo/brazilian-data-protection-law.pdf) · [加拿大 PIPEDA](https://laws-lois.justice.gc.ca/eng/acts/P-8.6/page-1.html) · [日本 PPC](https://www.ppc.go.jp/en/legal/)

## 发布边界

- 用户使用更新后的部署目录覆盖网站。正式域名须能匿名打开中文 HTML，并与 APK 内正文一致。当前域名未解析，公网访问和应用市场审核均待验证。域名托管由用户操作。 [华为隐私政策链接规范](https://developer.huawei.com/consumer/cn/doc/App/50128/)
- 当前产品适用于单机分发流程，申报仍以后台和最终核准为准。处理隐私请求时遵守适用的回复期限。华为审核指南中无承诺时限的上限为 15 个工作日。 [单机应用核准指引](https://developer.huawei.com/consumer/cn/doc/App/50130/) · [华为审核指南](https://developer.huawei.com/consumer/cn/doc/doccenter-submission/50104/)
- 对外分发 APK 时保留其精确提交和可取得的对应源码。后续实质修改政策正文时，网站和下一份签名包一并更新。 [GPL-3.0 第 6 节](https://www.gnu.org/licenses/gpl-3.0.html)

## 实际结果

- 同一份 HTML 源文件由官网发布，构建时原样打包进 APK。应用从内置文件显示正文、日期和目录，禁止内置阅读器加载联网资源。外部链接仅在用户点击时委托浏览器或邮件应用。没有新增联网权限或 SDK。
- 首启和旧版升级先展示声明入口与明确选择。撤回时结束本次会话，清除已解密数据和缓存，保留加密库。自动测试覆盖查看/返回、拒绝/重新选择、同意记录写入失败、旧修订重新确认、撤回取消及恢复使用，加密文件内容保持一致。扫码授权单独触发，未授权和拒绝可回到图片或手动输入。
- 本机 `make ci` 通过。核心 105 项，行覆盖 94.50%，分支 70.59%。App 182 项，行覆盖 83.83%，分支 59.76%。Python 42 项，包含备份互通相关检查。两种构建的 Lint、令牌扫描、权限、存储排除、16 KiB 对齐门禁均通过。
- Chrome 验证 1440、768、700、390、320 像素宽度的首页与声明，检查键盘焦点、页面往返、锚点、资源和网络请求。两个页面直接返回 HTTP 200，未发起第三方请求。
- 0.5.1 的签名、权限、资源一致性和哈希实测见本机 `dist/releases/v0.5.1/build-info.json` 和 `SHA256SUMS`。本次没有连接手机或配置模拟器，真机上的离线渲染、相机、系统身份验证和覆盖安装未验证。
