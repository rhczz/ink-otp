# InkOTP 0.5.4-beta.1

Android、macOS 和 iOS 从这个版本起共用一个版本号和一个 GitHub Release。在下方 **Assets** 下载所需的平台版本，并使用 `SHA256SUMS` 核对文件。

Android 版本代码为 11。已有用户建议先导出加密备份，再覆盖安装。macOS 用户打开 DMG 后，将 InkOTP 拖入「应用程序」。临时签名的 Beta 中，受保护的 Keychain 进门验证不可用，建议设置恢复口令并保留加密备份。

Apple 系统包信息显示 `0.5.4`，App 的版本信息和下载页显示完整的 `0.5.4-beta.1`。

真机验收仍包括 Android 与 iOS 的安装、覆盖升级、相机及系统身份验证，以及 macOS 的安装和系统 Keychain 行为。
