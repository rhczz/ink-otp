# InkOTP 0.4.0-beta.1

Android 离线验证器测试版，包名 `io.github.rhczz.inkotp`，versionCode 3，支持 Android 8.0（API 26）及以上。应用不联网。项目采用 GPL-3.0 许可。

## 这版包含什么

- 使用 Android 标准系统认证界面；不读取或保存手机 PIN、图案或密码。
- 支持 InkOTP 原生备份以及 Aegis、2FAS 和 otpauth URI 互通；导入不兼容内容时给出明确反馈。
- 优化前台出码缓存与轮询，后台停止不必要的更新，锁定时清理缓存。
- 发布安装包固定签名，附带 SHA-256 校验和与构建来源说明。

本轮本地基线为 core 105 项、App 129 项测试通过，均无失败和跳过；core 行/分支覆盖率 94.503% / 70.588%，App 为 79.647% / 53.771%。tag 发布会再次执行 CI，以该次运行及随附构建信息为准。

1000 账号宿主基准中，缓存路径 p95 为 0.020208 ms，基线为 0.567667 ms；30 秒内 HMAC 次数下降 96.7%。这些是宿主测量，不能代表所有 Android 手机性能。

## 安装与验证

下载 `InkOTP-0.4.0-beta.1.apk`，可用 `SHA256SUMS` 核对下载完整性。公开签名证书 SHA-256 为 `f1e8211a3f245bed886a048f8088b16be229072dcf77b65981e6ca5dcf642589`，与既有本地 beta 使用同一身份。

请在真机测试安装和覆盖升级、系统认证成功/失败/取消、切后台与锁定、相机扫码及格式导入导出，并反馈 Android 版本、机型、操作步骤和现象。不要提交真实 OTP 密钥、恢复口令或私钥。

系统认证、相机与不同 Android/硬件上的行为、覆盖升级及真实手机性能尚未完成用户真机验收；M3 真机验收保持待测。
