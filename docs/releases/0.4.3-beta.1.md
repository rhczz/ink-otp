# InkOTP 0.4.3-beta.1

- 关闭「每次进入时验证身份」后直接打开验证码库。已有库升级时可能需要一次系统验证或恢复口令来更新本机密钥包装。开启该选项后使用 Android 系统验证。
- 剪贴板清理改成单选列表，提供关闭、立即、15 秒、30 秒和 60 秒。清理之前核对该条内容仍来自 InkOTP 最近一次复制。
- 正式包补强最近任务、悬浮窗和遮挡触摸防护。使用隐藏验证码时可继续复制当前验证码。
- 添加菜单只显示一根拖动条。开源许可提供源码仓库链接。诊断页重新计算验证码与刷新资源统计可以独立操作。

可从使用相同签名的旧版覆盖安装，保留本机账号。真机专项复测见本次变更记录。
