# InkOTP 0.6.0-beta.1

- 三端改善备份导入确认。合并、替换和取消各有清晰的操作位置，替换前会再次提示。
- 三端支持 Google Authenticator 迁移二维码。导入可收集整批二维码再保存，导出会标明可以迁移的账号和格式限制。HOTP 账号保留计数器供迁移，出码需要支持 HOTP 的验证器。
- 旧版 InkOTP `.2fab` 文件自本版起停止读写。常规备份使用 Aegis 加密格式。
- 打开验证码列表时，卡片从上到下轻轻落位。系统开启减少动态效果时直接显示。

Google Authenticator 双向迁移、Android 和 iOS 的系统认证与真机安装仍待设备实测。
