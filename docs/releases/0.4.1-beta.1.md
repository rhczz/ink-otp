# InkOTP 0.4.1-beta.1

修复 0.4 手机试用反馈，包名 `io.github.rhczz.inkotp`，versionCode 4，支持 Android 8.0 及以上。

- 解锁自动调用系统认证，取消后可主动重试；使用普通按钮代替自绘大指纹入口，系统认证中的恢复口令按钮直接打开应用口令表单。
- 设置及其他保存操作保持页面亮度，短操作不闪全屏遮罩；持续操作延迟显示进度，保留重复操作拦截。
- 列表与详情的验证码在最后五秒与倒计时同步使用警告色，新周期恢复。
- 已核查相册访问：系统选择器只交付用户选中的图片，不申请全部相册或存储读取权限，无需新增“部分/全部访问”弹窗。

使用既有签名，可覆盖安装 `0.4.0-beta.1`，不需要卸载或重新建库；本机库与备份格式保持兼容。完整真机覆盖升级仍须用户复测。Android 8–8.1 及少数兼容设备由 AndroidX 提供官方兼容认证界面，其余支持设备使用系统认证样式。

本轮 core 105 项、App 150 项、Python 42 项测试全部通过，无失败或跳过；Debug/Release 构建与 Lint、格式对拍、权限、固定签名和 16 KiB 对齐通过。core 行/分支覆盖率为 94.503% / 70.588%，App 为 82.072% / 56.861%。详情见 [修复记录](../changes/2026-11-17-phone-feedback-fixes.md)。

本版本通过 `v0.4.1-beta.1` tag 触发的 GitHub 流水线验证、签名并发布，安装包附带校验和与构建来源。真机指纹成功/失败/取消反馈、连续点击闪屏、前后台切换、浅深色末五秒颜色、选图/取消和保留数据的覆盖升级仍待复测，不能用电脑测试代替硬件验收。
