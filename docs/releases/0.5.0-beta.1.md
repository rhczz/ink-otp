# InkOTP 0.5 Android 公测

这是 InkOTP 的首个公开测试版，适用于 Android 8.0 及以上。InkOTP 在设备上生成 TOTP，不申请网络权限。公测通过 GitHub 提供签名 APK。

- **备份恢复**可从首启或锁定页开始。恢复已有库前明确确认替换，保留原库加密副本。已开启每次进入验证时须通过 Android 系统验证。选择文件和解密备份时都可取消。
- **新版标志**采用两组三片的原创图形，对应六位验证码，并支持 Android 主题图标。
- **诊断与大字号**加入系统日期与时间设置入口，将时间、账号和密钥列为自查项。添加菜单能够换行和滚动。

已有用户请先导出一份加密备份，再直接覆盖安装。记住备份导出时使用的口令。正常升级无需卸载旧版。现有签名、包名与备份格式继续沿用。

系统认证、相机、实际覆盖升级、重装和换机恢复、Aegis/2FAS 双向互通及手机性能仍待设备验证。参加公测时可先用测试账号走完导出和恢复，再迁移日常账号。
