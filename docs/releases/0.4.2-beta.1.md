# InkOTP 0.4.2-beta.1

修复隐藏验证码的复制行为，包名 `io.github.rhczz.inkotp`，versionCode 5，支持 Android 8.0 及以上。

- 开启“隐藏验证码”后，点击列表卡片从第一次起就复制正确的验证码，页面始终显示圆点。
- 详情页的复制和周期刷新也保持隐藏，移除临时显示本轮验证码的操作；无障碍读屏不因复制而透露数字。
- 只有关闭隐藏设置才恢复显示。最后五秒的警告颜色及既有剪贴板清理继续有效。

认证行为保持原有设计。用户已确认设置恢复口令后系统认证正常，无恢复口令模式不新增系统认证。备份、账号库格式和签名身份均不变，使用此 APK 直接覆盖升级，无需卸载。

本机 core 105 项、App 154 项、Python 42 项测试均通过，无失败或跳过；Debug/Release 构建、Lint、权限、签名和对齐检查通过。Core 行/分支覆盖率为 94.503% / 70.588%，App 为 82.496% / 55.814%。

本版本通过 `v0.4.2-beta.1` tag 的既有流水线验证、签名和发布，附带 SHA256SUMS 与构建来源。实际远端结果见 [修复记录](../changes/2026-11-17-hidden-copy-and-device-lock.md)。真机复制粘贴、TalkBack、长按进出详情、换码与覆盖升级仍待用户复测，不能用自动测试代替硬件验收。
