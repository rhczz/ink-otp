# M4 内测：安装与手机验证

版本：`0.4.2-beta.1`，包名 `io.github.rhczz.inkotp`，Android 8.0 及以上。

## 安装与已有数据

使用 `dist/InkOTP-0.4.2-beta.1.apk` 覆盖安装即可。签名沿用 M3/M4，versionCode 从 4 增为 5；不需要数据线、Android Studio 或与电脑保持连接。已有本机库和旧 `.2fab` 文件的布局不变。

安装前可先在旧版导出一份备份。日常试用不需要卸载旧版；普通完整卸载会删除应用自己的库和密钥，只有你主动导出的备份可用于恢复。

## 每次进入时验证身份

1. 打开“设置”，先设置并记住应用恢复口令。
2. 开启“每次进入时验证身份”，按系统弹窗完成确认。
3. 切到其他 App 再返回，应该先出现验证，成功后才能看账号；点击取消应保持锁定。
4. 在锁定页手动再次验证，应能重新进入。关闭开关也应要求一次新的系统确认。
5. 旋转屏幕不应绕过锁定或循环弹窗。系统验证超时后应保持锁定，可以重试。

Android 11+ 使用系统允许的强指纹、人脸或锁屏 PIN/图案/密码。Android 8–10 使用系统锁屏凭据确认。设备不支持的普通人脸不会被应用自行代替。手机锁屏密码只在系统界面输入；应用内“恢复口令”是另一个由你设置的口令。

更改应用恢复口令、导入替换或系统密钥失效后，开关仍保持开启；如果需要重绑，先输入应用恢复口令，再完成系统确认。恢复口令本身不能跳过已开启的系统验证。手机验证不可用时先恢复手机锁屏设置。

## 0.4 手机反馈专项复测（待用户反馈）

请优先验证以下项目，并保留旧账号，不要卸载重装：

1. 覆盖安装后账号、恢复口令、生物识别及每次进入验证设置仍在；旧版备份仍能进入导入预览，取消后本机内容不变。
2. 普通生物识别解锁和每次进入验证都应自动出现系统认证。用错误指纹、成功指纹、返回/取消分别测试；取消后停留锁定页，不能反复自动弹出，主动点击“使用系统验证”可重试。
3. 普通生物识别系统界面里的“使用恢复口令”应直接进入应用口令表单。手机 PIN/图案/密码始终在系统界面输入。旋转、切后台、返回和手动锁定不能让旧认证结果解锁新会话。
4. 连续点击设置中的自动锁定、隐藏验证码、剪贴板清理，观察整屏是否还会瞬时变亮/变暗。设置页返回、详情排序/保存、添加、备份等共用流程也需观察；长操作可以有小进度提示，背景保持亮度且不能重复提交。
5. 在列表和详情分别观察剩余 6→5→1→新周期：最后五秒数字、环和秒数应同为警告色，新周期恢复。浅色/深色、6/8 位都需检查；开启隐藏后，首击/连续点击列表、详情复制按钮、长按进出详情和换码均应保持圆点，粘贴到目标 App 应得到正确验证码，读屏只读“验证码已隐藏”。相关修复见 [0.4.2 记录](../changes/2026-11-17-hidden-copy-and-device-lock.md)。
6. 从相册选择一张二维码图并完成解析，再测试取消、无二维码/损坏图片。系统选择器展示所有图片供选择是正常行为，应用只读取主动选择的那张，不申请整个相册权限。是否出现额外厂商对话框取决于系统/图库，应用没有“部分/全部相册访问”的运行时申请。

Android 8–8.1 及少数 AndroidX 兼容机型可能显示官方兼容指纹对话框，不能承诺每台手机与新 Android 的样式一致。指纹触觉、厂商动画、真实帧连续性与以上升级流程仍未在本机验证，自动测试通过不代表这些专项已验收。实现与证据见 [手机反馈修复记录](../changes/2026-11-17-phone-feedback-fixes.md)。

用户主动进入系统文件选择器属于当前操作，最多保留 60 秒；系统认证本身最多 120 秒。普通切出与返回没有这条例外。切换 App 粘贴刚复制的验证码仍遵守剪贴板清理时限。

## 与其他验证器互通

“导出备份”先选格式，再验证当前应用恢复口令。默认 Aegis 加密 JSON；也可选 2FAS 加密备份、两种明文 JSON、otpauth 文本或旧 InkOTP `.2fab`。来源外观、图标、分组等信息不能完整映射时会先说明。

明文交换文件包含完整账号种子，必须额外确认才会打开保存位置。它适合主动迁移，文件是否保留由你管理。

“导入备份”使用系统文件选择器。加密文件输入它原来的备份口令；明文文件直接进入预览。先检查来源、账号数量和兼容性说明，再选择合并或替换。导入后继续使用本机应用恢复口令，不会自动换成来源文件的口令。

HOTP 账号会保留参数与计数器并可再导出，当前界面暂不生成 HOTP 码；日常出码使用 TOTP。

兼容范围是 [格式矩阵](../../spec/interoperability.md) 中的版本与 OTP 参数。若遇到 Steam、7 位码等当前不支持的条目，会整份拒绝并提示序号，不把部分成功当作迁移完整成功。无法承诺所有验证器、所有历史和未来版本都能互通。

建议先用公开测试账号做一次 Aegis/2FAS 双向导入，确认参数和当前码相同，再迁移真实账号。官方样本和独立解密对拍已自动验证，来源 App 的界面内导入仍待这一步手机确认。

## 性能和资源

诊断页点击“刷新状态”可按需查看进程 PSS、Java/原生堆、私有文件逻辑大小和最近操作耗时。几种内存统计有重叠，不能相加；大小不包含外部备份或系统 Keystore。耗时包含用户验证等待，不能单独视为计算耗时。

请观察首次进入、长列表滚动、30 秒换码、导入导出是否流畅，切到后台后是否持续明显发热。应用锁定和后台不运行验证码轮询，也没有资源采样后台服务；真实手机的启动时间、内存峰值、帧率和耗电尚无实测结论。

如需要专门测卸载清理，请先确保备份可恢复，再使用公开测试账号或备用环境操作：完整卸载后重新安装应进入首次引导，旧本机库不能自动恢复；用户先前导出的文件仍应保留。不要把“归档”或勾选保留数据当作普通完整卸载。
