# macOS 桌面版规格

以公开发布的 Android 0.5.3（`v0.5.3`）为基准。Apple Silicon 与 Intel 使用同一份应用源码，最低支持 macOS 14。保留 Quiet Ink 的配色与验证码层级，采用 SwiftUI 分栏、菜单栏、工具栏、原生文件面板与键盘导航。应用和备份内容全程离线。

## 架构与数据

- `macos/Sources/InkOTPCore` 负责 OTP、Base32、URI、本机库与交换格式。App 分为状态与仓储、平台适配及桌面视图。Android/iOS/macOS 的实现以同一份公共合约验收。
- 私有库使用该 App 沙箱内的 Application Support。写入同时校验模型并原子替换。随机设备数据密钥由本机 Keychain 管理，启用每次验证时使用 macOS 系统认证。恢复口令由 App 管理，独立于设备登录口令。导出由用户在系统保存面板中选择位置。
- 跨端恢复使用既有 Aegis、2FAS、otpauth 和旧版 .2fab。支持矩阵和资源上限沿用 [交换规格](interoperability.md)；本地包装密钥不会通过交换文件传递。

## 用户可见行为

- 首次启动支持隐私说明、同意与撤回、空库创建与备份恢复。已解锁支持搜索、选择、手动添加、粘贴 URI、从图片或相机读取二维码、编辑、删除、重新排序。
- TOTP 显示周期和尾五秒提醒，和 Android 0.5.3 一样，已导入的 HOTP 保留完整账号与计数器并可导出，桌面上不手动新建、出码、复制或推进 HOTP。启用隐藏后，只有在设置中关闭隐藏才恢复显示，TOTP 可复制但不在界面或 VoiceOver 中揭示；按剪贴板策略清除，与其他应用后续复制隔离。
- 锁定、系统休眠和会话锁屏清除出码投影。按设置处理失焦自动锁定和每次进入验证。支持更改恢复口令、导入预览和合并、默认加密导出、明文风险确认、离线隐私说明、版本及许可、时钟诊断。
- 切换到其他应用时，主窗口及敏感弹层隐藏账号与验证码，同时从辅助功能树移除敏感内容。超时自动锁定后，回到应用通过已配置的设备钥匙串路径恢复。主动锁定后保留解锁按钮，系统认证取消后等待用户重试。系统认证弹窗使应用失焦时最多保留两分钟，到期后取消该授权并锁定。手动添加接受裸 Base32 与完整设置链接，并在保存前显示解析的参数。
- 临时签名版本覆盖升级时，旧签名的普通钥匙串项目可能要求系统重新授权。普通自动解锁只使用已授权的钥匙串读取；主动点击解锁时可由 macOS 钥匙串询问原项目访问授权。用户验证恢复口令后，可在现有库内容和安全设置不变的情况下原子绑定当前签名的设备凭据；失败时保留原库和恢复能力。
- 诊断中的重新计算操作以当前时间重新生成已解锁的 TOTP，并保持资源采样独立。关于页和申请相机权限前均可阅读随包隐私声明，返回不触发系统授权。
- 拖入图片或使用文件菜单操作；常用操作提供键盘入口；浅深色跟随系统。

## 验收

- GitHub Actions 运行公共 OTP、URI、备份与协议失败用例，验证 macOS 输出由独立 Python 参考实现读取。Android 和 iOS 也验证同一批向量与样本，并在 GitHub Actions 上互读实际导出文件。
- GitHub Actions 构建和测试两种架构、检查沙箱与离线权限、验证分发包，并通过单独的 macOS 版本标签发布。发布记录注明签名状态。临时签名公测版的每次进入验证受 [EX-008](../docs/exceptions.md) 限制，正式版要求 Developer ID、授权 Keychain 的描述文件与 Apple 公证。
- 真实 Mac 验收需覆盖首次安装、覆盖升级、Touch ID 与系统密码、拒绝和取消认证、系统休眠、相机与文件权限、VoiceOver 与剪贴板；CI 的执行结果和实际设备结果分别记录。
