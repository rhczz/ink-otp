在设备上生成两步验证码

在 Android 设备上扫码添加账号，离线获取一次性验证码。验证密钥加密保存在本机，换机时可用加密备份恢复。

下载 Android 版 ↗
  • 支持 Android 8.0 及以上
  • GPL-3.0 开源

主要功能

适用于支持 TOTP 的邮箱、开发平台及其他服务。

添加和查找账号
用相机扫码、从图片选择二维码，或手动输入密钥。登录时搜索账号，轻点即可复制当前验证码。
按需验证身份
可隐藏验证码、设置自动锁定，并通过设备提供的系统身份验证保护应用入口。
导出与恢复
将加密备份保存到自己选择的位置。换机或重装后，可以从首次启动页恢复账号。

安装与换机

在 GitHub 的版本页打开 Assets，下载扩展名为 .apk 的 Android 安装包。覆盖更新前请先导出加密备份，并保管好恢复口令。
