隐私声明

InkOTP 在你的设备上生成两步验证码。任红昌是 InkOTP 的开发者，也是官网运营者。关于隐私的问题可发至 hi@renhongchang.top。

修订日期 2026 年 11 月 18 日

适用范围

本声明适用于 InkOTP 离线验证器 0.5.1 及采用本声明的后续版本、InkOTP 官网和开发者的隐私联系渠道。应用无需注册 InkOTP 账号。创建、查看和管理验证码所需的信息由应用在设备上处理，开发者无法通过应用取得账号、密钥、验证码、相机画面或备份内容。

首次使用时，你可以查看全文，并选择是否开始使用应用。确认仅保存在设备上，用于记录你对当前声明的选择。每个可选功能按其用途单独启用。浏览官网、联系开发者或访问外部服务时，相关信息依照下文和所用服务的说明处理。

应用内处理与权限

验证码账号与设置
添加或导入账号时，应用处理你提供的服务名称、账号标识、验证密钥以及算法、位数、周期或计数器等参数。应用将验证密钥与设备时间用于生成基于时间的验证码。账号顺序、锁定方式、清理间隔等设置保存在设备上。
相机
你主动选择扫码并请求授权后，应用在扫码界面即时读取相机画面，只用于识别验证二维码。原始画面不会被应用保存。你可以拒绝或在设备设置中撤回相机权限，继续从选定图片导入或手动输入密钥。
图片与文件
从图片读取二维码、导入备份或导出文件时，应用通过系统选择界面访问你选定的图片、文件或保存位置。识别结果或导入内容按你确认的操作写入验证码库。应用不会扫描你的照片库。选择联网或同步的文件位置时，相关文件可由该位置的服务商按其规则处理。
设备身份验证与界面保护
应用可用设备提供的密钥保护验证码库。你启用了入口身份验证等需要认证的功能时，系统会核验身份，应用接收认证结果，并按需执行经系统授权的密钥操作。指纹、人脸模板和锁屏凭据由系统管理。应用在设备支持时可限制截屏或第三方悬浮窗，降低验证码在屏幕上暴露的可能性。
剪贴板
你主动复制的验证码会进入系统剪贴板。应用按照清理设置检查自己写入内容的标记和时间戳，并尝试清除该条内容。实际清理取决于设备系统。拥有相应权限的功能、应用或设备间剪贴板服务可能接触剪贴板内容。
本机诊断
应用读取本机时间和可用的自动时间状态以协助排查出码问题。查看资源诊断时，可在本机显示应用内存、私有文件大小和操作耗时。诊断结果不向开发者上报。

当前版本的验证功能可离线使用，应用未接入广告、使用统计、用户追踪、崩溃上报或远程账号同步。申请相机以及使用设备提供的身份验证不会将验证密钥或认证凭据发送给开发者。

保存、备份与删除

  • 验证码库加密存放在应用私有空间，密钥由设备密钥或恢复口令保护。应用将私有数据配置为排除在其支持的系统自动备份和设备迁移之外。实际设备能力由系统提供。
  • 账号、设置与库随你在设备上的使用继续保存。你可在账号详情查看服务名、账号标识与验证码参数，修改服务名或账号标识，并从当前库删除条目。需要备份或转移时可主动导出。救援恢复替换库时可能保留一份加密旧库，直到下次替换式救援恢复覆盖该副本、清除应用数据或卸载。清除应用数据或按正常方式卸载，会移除应用私有空间中的活动库、救援副本和设置。
  • 由你主动导出的文件保存在你选择的位置。应用默认提供加密导出。你明确确认明文迁移时，文件包含可用于生成验证码的密钥。建议优先使用加密备份，不随文件一起发送口令，并按需从保存位置删除副本。卸载应用也请到保存位置管理导出文件。
  • 设备丢失、恢复口令遗忘、备份损坏或丢失时，开发者没有可用于代你恢复的数据。若密钥可能外泄，可在对应账号服务中撤销并重新设置两步验证。加密、系统认证和剪贴板清理只能降低风险，实际保护还取决于设备及你保管备份的方式。

本机组件

随应用分发的组件在设备上完成下列工作。应用没有通过这些组件向组件开发者发送你的验证码账号、密钥、图片或备份。组件按所用功能工作，设备支持能力取决于系统和硬件。主动打开下列外部链接时，才会访问对应的外部网站。

Jetpack（含 Compose、CameraX 和 Biometric）
由 Google 的开源项目维护。界面与设置涉及在设备上显示和保存的内容。扫码时 CameraX 提供本机图像帧。Biometric 调用系统验证并返回结果。维护者网站隐私说明
ZXing Core
由 ZXing 开源项目维护。只在设备上从相机帧或选定图片读取二维码及其中的内容。项目说明
Bouncy Castle
由 Legion of the Bouncy Castle 开源项目维护。在设备上使用口令、盐值等参数派生加密密钥。维护者网站隐私说明
Kotlinx Serialization 与 Kotlinx Coroutines
由 JetBrains 的开源项目维护。前者在设备上读写账号库和备份的结构化数据，后者调度本机任务。维护者网站隐私说明

官网访问与邮件

官网访问
官网提供产品、下载、源码和隐私信息。网站页面未集成账号、表单、广告或访问分析脚本，也不在页面中设置 Cookie。浏览器访问网站时，托管及网络安全服务可能处理 IP 地址、请求时间、访问路径、浏览器信息和安全事件，用于交付网站、防滥用及排障。若托管层启用安全验证，它可能使用为该功能所需的 Cookie。相关记录按照交付与安全所需期限及实际服务设置保留。
联系开发者
你主动发送邮件时，开发者及邮件路由和存储服务会处理你的邮件地址、邮件头、正文及你附带的内容，以接收、核实、处理和回复请求。开发者在办理、跟进及依法需要的最短期限内保留记录，期限届满后删除或依法限制处理。请只提供必要信息，勿发送密钥、验证码、恢复口令、备份或包含它们的截图。
委托服务与披露
开发者在交付网站、保障安全、处理你的请求或履行法定义务所需的范围内处理相关信息。依适用法律须征得同意时，会在相应处理前征求同意。为提供这些功能所必需的信息可能由托管、安全及邮件服务处理，或依法向有权机关提供。开发者不出售这些信息，也不将其用于定向广告。处理地点取决于实际使用的服务。涉及跨境处理时，开发者按适用要求履行告知、取得所需授权并采取相应保护。
外部服务
你主动打开外部链接、选择下载或在外部渠道反馈时，浏览器、邮件客户端或外部服务可能按各自规则处理信息。官网链接所指的代码与下载仓库由 GitHub 提供。GitHub 隐私声明

如何行使权利

你可以在设备上查阅、修改、导出或删除验证码账号，关闭可选功能，按系统设置撤回相机权限，或在应用设置中撤回对使用应用的确认。撤回会结束当前使用，设备上的库仍由你管理，依法撤回同意不影响撤回前基于同意进行的处理。需要删除整个库时，可以清除应用数据或卸载，再按需处理自行保存的导出文件。

就开发者可以访问的信息，你可以按适用法律请求说明、查阅、复制、更正、删除、限制处理、转移、反对或撤回同意，也可以提出投诉。请联系 hi@renhongchang.top，说明希望处理的事项。开发者仅在必要时核实你的身份，在适用期限内处理并回复。如依法无法满足请求，会说明原因。你也可以向有管辖权的个人信息保护或数据保护机构投诉。

如果发现安全问题，可通过上述邮箱或 GitHub 私密安全报告联系。若发生影响开发者所处理个人信息的安全事件，开发者将按适用法律采取补救措施并履行通知义务。

未成年人及更新

InkOTP 面向一般用户。依法需要监护人同意时，请在监护人同意和指导下使用。请勿由儿童自行通过邮件提供个人信息。监护人可联系开发者管理或删除其通过联系渠道提供的信息，开发者会按适用规则处理。

声明更新时会同步更新修订日期。处理目的、方式或信息种类等有实质变化时，开发者会在变化生效前以适当方式告知，并在需要时重新征求同意。你依适用法律享有的权利继续有效。
